Runs locally at 127.0.0.1:8000. Configure Gmail (IMAP App Password) and SEQTA in .env, or import SEQTA JSON.

Setup / Import

Easiest Gmail setup (no Google Cloud/OAuth): use a Google App Password. In your Google account: turn on 2‑Step Verification, then create an App Password at myaccount.google.com/apppasswords. Paste it below and save. Personal Gmail usually works; some school/work accounts block app passwords/IMAP.

Gmail accounts (App Password)

SEQTA import (easy fallback)

Paste your timetable/assignments JSON below. This is saved locally and used when SEQTA mode is import.

Advanced: SEQTA automation (Playwright)

If you want to try automation, edit .env: set SEQTA_MODE=playwright, fill SEQTA_BASE_URL, SEQTA_USERNAME, SEQTA_PASSWORD, and URLs/selectors. Install with pip install -r requirements-seqta.txt && python -m playwright install chromium. This is school-specific and may need tweaking.
